# БЕЗ МЕЖ — сайт (новий)

🌐 **Живий сайт:** https://pashawilliams.github.io/bez-mezh-site/

Статичний односторінковий сайт пасажирських перевезень **БЕЗ МЕЖ** (Україна ⇄ Європа):
тарифи за часом у дорозі, класи Comfort (08:00) / Lux (18:00), ціни в гривнях за курсом НБУ.

Зібрано на базі архітектури Eurotour (`site`), контент і бренд — БЕЗ МЕЖ.

## Що всередині

- `index.html` — головна: пошук, 74 картки рейсів, послуги, відгуки, FAQ, контакти
- `chat.html` — онлайн-чат з менеджером
- `data/site.json` — весь редагований контент + тарифи + тривалості (читає сайт і бот)
- `data/cities.json` — 129 міст з координатами
- `js/pricing.js` — тарифний рушій (ціна = час у дорозі + клас)
- `js/route-prices.js` — міста, координати, фолбек-ціни
- `bot/bot.py` — Telegram-бот адмінка (контент, заявки, чати)
- `src/build_data.py` — збірка даних (OSRM + site.json)
- `src/port_site.py` — скрипт переносу/ребрендингу (історія, запускався 1 раз)
- `docs/SITE_STUDY.md` — розбір оригінального bez-mezh.com.ua

## Міста та тарифи

- **136 міст у пошуку:** 63 UA + 73 EU (Німеччина, Чехія, Бельгія, Нідерланди, Польща, Австрія, Словаччина, Угорщина, Італія, Франція, Іспанія, Румунія, Молдова + КПП)
- **74 рейси картками**, решта пар — через пошук (ціна рахується автоматично)
- Тарифи: 17 рядків 6–8 год → 90/120 € … 45+ год → 250/290 €, +3 год на кордон
- Знижки: пенсіонерам −10%, дітям −15%

## Деплой та бот

- Гілка `main`. Push → GitHub Actions → GitHub Pages (~2 хв).
- Бот-воркфлоу **вимкнено**, доки не буде секретів. Для ввімкнення потрібні
  repository secrets: `BOT_TOKEN` (BotFather), `ADMIN_ID` (Telegram ID),
  `GH_PAT` (contents:write), опційно `STATE_SECRET`. Потім: `gh workflow enable bot.yml`.
- Канал заявок/чату: ntfy-топік з `data/site.json → bridge.inbox` (унікальний для цього сайту).
