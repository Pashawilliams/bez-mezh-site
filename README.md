# bez-mezh-site

Рабочая область для сайта пассажирских перевозок **БЕЗ МЕЖ** — https://bez-mezh.com.ua/ru/

Здесь ведём анализ, структуру, тексты и доработки, связанные с сайтом.

## Оригинальный сайт

- **Компания:** БЕЗ МЕЖ (группа компаний «Без границ»)
- **Тематика:** регулярные пассажирские перевозки микроавтобусами Mercedes-Benz Sprinter (7 мест)
- **Направления:** Украина ⇄ Германия, Чехия, Бельгия, Нидерланды + VIP-трансфер (Европа, Турция, Грузия)
- **Технологии:** WordPress + Elementor, Rank Math SEO
- **Языки:** RU / UA
- **Масштаб:** ~1270 страниц рейсов (по лендингу на каждое направление), 10 категорий рейсов
- **Расписание:** отправления через день, по чётным числам
- **Классы:** «Комфорт» (~200–270 €) и «Комфорт+ (реклайнер)» (+20–40 €)

Подробный разбор — в [docs/SITE_STUDY.md](docs/SITE_STUDY.md).

## Структура репозитория

```
bez-mezh-site/
├── README.md            # этот файл
├── docs/
│   └── SITE_STUDY.md    # полный отчёт об изучении сайта
├── data/
│   └── reys-urls.txt    # все URL страниц рейсов из sitemap.xml (~1273 шт.)
└── src/                 # будущие наработки (скрипты, парсинг, шаблоны)
```

## Как работаем

1. Все задачи по сайту фиксируем и делаем в этом репозитории.
2. Данные (выгрузки, таблицы) — в `data/`.
3. Документы и отчёты — в `docs/`.
4. Код (парсеры, скрипты, правки) — в `src/`.
