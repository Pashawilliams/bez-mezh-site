# Eurotour — полное описание сайта (спецификация для воспроизведения)

## 1. Что это
Одностраничный сайт‑лендинг пассажирского перевозчика «Eurotour» (Україна ↔ Європа) с:
- поиском/бронированием рейсов, каталогом маршрутов и цен;
- формами заявок (бронирование, посылка, трансфер, обратный звонок, отзыв);
- онлайн‑чатом с менеджером (отдельная страница) с обменом файлами;
- админ‑панелью в Telegram‑боте, которая редактирует контент сайта без кода.

Язык интерфейса — украинский. Брендинг: логотип EURO TOUR, фиолетово‑белая палитра.

## 2. Технологии и хостинг
- **Чистые HTML + CSS + JS** (без фреймворков и сборки). Всё статично.
- Хостинг: **GitHub Pages** из ветки `main` репозитория `Pashawilliams/site`, деплой через GitHub Actions (`.github/workflows/deploy.yml`, ~2 мин).
- Домен: `eurotour.pp.ua` (NIC.UA), файл `CNAME` в корне репозитория; DNS: 4 A‑записи GitHub (185.199.108–111.153) + `www` CNAME → `pashawilliams.github.io.`
- Бэкенд отсутствует. Вместо него:
  - **`data/site.json`** — «база данных» контента (правится ботом, читается сайтом);
  - **ntfy.sh** (бесплатный pub/sub по HTTP) — канал сообщений сайт ↔ бот (заявки, чат, файлы);
  - **Telegram Bot API** — интерфейс администратора;
  - **GitHub Actions** — «сервер» для бота (запускается по расписанию, живёт 5 ч 20 мин, сам себя перезапускает).

## 4. Дизайн‑система (css/light-v6.css)
CSS‑переменные:
```
--dt-bg:#fff; --dt-bg-2:#f6f5fb; --dt-surface-2:#f3f1fa; --dt-surface-3:#ebe7f5
--dt-text:#130c5a (тёмно‑синий, основной текст/заголовки); --dt-text-2:#444d56; --dt-text-3:#7d7a99
--dt-accent:#4e1986; --dt-accent-2:#6e137d; --dt-accent-3:#f1e8fb (лавандовая подложка)
--dt-navy:#130c5a; --dt-navy-2:#37357b
--dt-grad: linear-gradient(96deg,#424083,#5b3f86,#37357b,#5c57b6)   (шапки, футер, аватары)
--dt-grad-btn: linear-gradient(94deg,#4e1986,#6e137d)                (кнопки)
--dt-border: rgba(19,12,90,.08); --dt-shadow: 10px 10px 50px rgba(56,70,97,.2)
--dt-radius:30px; --dt-radius-lg:40px
```
- Шрифт Fixel Display (400/500/700/800), fallback system‑ui.
- Карточки: белые, радиус 28–30px, тонкая рамка, мягкая тень; при hover приподнимаются.
- Кнопки: pill/скруглённые 12–16px, градиент; Telegram `#1e96c8`, WhatsApp `#1ea952`, звонок — navy.
- Анимации: `.et-reveal` (появление при скролле через IntersectionObserver), каскадные задержки `--i`, `prefers-reduced-motion` учитывается, тяжёлые blur/backdrop‑filter не применяются массово (лаги на мобильных).
- Брейкпоинты: ≤767 телефон, 768–1099 планшет, ≥1100 десктоп. `viewport-fit=cover`, везде `env(safe-area-inset-*)`.

## 5. Разделы index.html (сверху вниз)
1. **Announcement‑бар** (fixed, тёмный): текст + ссылка, управляется ботом (`site.announcement`).
2. **Шапка** (`.header`, sticky, становится компактной при скролле >40px): логотип, меню ГОЛОВНА · МАРШРУТИ(▾) · ПОСЛУГИ(▾) · ПЕРЕВАГИ · ВІДГУКИ · ПИТАННЯ · КОНТАКТИ; справа иконки Telegram / WhatsApp / телефон + номер. Мобайл: бургер → полноэкранное меню с контактами и строками менеджеров (`.et-mobile-mgrs`).
3. **Hero** (`.front-sec`, `#main-search-route`): фон — фото автобуса с лёгким blur, заголовок/подзаголовок (из site.json), счётчики «50+ напрямків · 24/7 підтримка · адреса→адреса», ниже **форма поиска** (`.search`): селекты «Звідки» `#search-from` / «Куди» `#search-to` (Київ, Львів, Варшава, Краків и др.), дата `#calendar2` (кастомный календарь), переключатель времени **08:00 / 18:00** (`.search__time`), кнопки «Знайти» `#search-button` и сброс `#reset-button`. Результат — прокрутка к маршруту и подсветка карточки.
4. **Преимущества** (`#advantages`): сетка иконок с текстом (список из site.json `advantages`, до 12).
5. **Маршруты** (`#routes`): карточки `.direction-element` (54 шт., атрибуты `data-from-name/data-to-name`), цена «від N грн», старая цена, бейдж, скрытие — всё из `routes[]`; первые N видны, остальные под «Показати всі» (`#direction-show-all`/`#direction-collapse`). Клик по карточке → popup бронирования с предзаполненным маршрутом/датой/временем.
6. **Услуги**: посылки (доставка по Європі), трансфер из аэропорта, оплата картой — каждая со своей формой.
7. **Отзывы** (`#reviews`): карточки с аватаром‑буквой, звёздами (SVG), текстом; данные `reviews[]`.
8. **FAQ** (`#faq`): первый вопрос — большая карточка, остальные — аккордеон `.et-acc`; данные `faq[]`.
9. **Контакты** (`#contacts`): 4 карточки `.et-ccard` (Telegram, WhatsApp, Телефон, «Написати зараз» → chat.html); блок **«Наші менеджери»** (`.et-managers__list`, карточки: аватар‑буква с зелёной точкой, имя + бейдж, роль, номер, кнопки Дзвінок/Telegram/WhatsApp); строка «Графік · Мова · Оплата».
10. **Футер**: логотип, колонки ссылок, номер поддержки + список менеджеров (`.et-footer-mgrs`), соцкнопки, © и ссылки на политику/оферту.
11. **Плавающие элементы**: прогресс‑бар чтения сверху; кнопка чата `#et-chat` (ссылка на chat.html, бейдж непрочитанных, тултип); «наверх»; на экранах <1100px — **нижняя док‑панель** `.et-mcta` (Telegram · WhatsApp · «Забронювати від N грн» · звонок), прижата к нижнему краю, всегда видна, скрывается только при открытом меню; учитывает клавиатуру/панель браузера через `visualViewport`.
12. **Окно выбора менеджера** `.et-pick` (js/managers.js): любой клик по ссылке `tel:` / `t.me` / `wa.me` (кроме карточек менеджеров и ссылки на бота) перехватывается и открывает шторку «Кому зателефонувати / написати?» со списком менеджеров; снизу на мобиле, по центру на десктопе; закрытие — фон/крестик/Esc.

## 6. Формы (js/local-forms.js)
- Виды: **booking** (имя, код страны + телефон, маршрут, дата, время 08:00/18:00), **delivery** (посылка), **transfer**, **callback/manager**, **payment**, **review**.
- Кастомный date‑picker (без freeze: MutationObserver только на childList), телефон с выпадающим списком кодов стран и маской, валидация на клиенте.
- Отправка: `window.siteBridgeLead({type, fields:{...}, context:{поиск}})` → POST JSON в ntfy‑topic `INBOX`; очередь в localStorage с повтором при сбое; пользователю тост «Заявку отримано». Бот присылает клиенту авто‑сообщение в чат.

## 7. Динамический контент (js/site-data.js + data/site.json)
Схема `site.json`:
```json
{
 "site": {"name","tagline","maintenance":false,"announcement":{"enabled","text","link"}},
 "contacts": {"phone","phone_display","telegram","whatsapp","support_note"},
 "managers": [{"name","role","phone","telegram","whatsapp"}],
 "hero": {"title","subtitle"},
 "advantages": ["..."],
 "routes": [{"from","to","price","old_price","badge","visible"}],
 "reviews": [{"name","text","rating","date"}],
 "faq": [{"q","a"}],
 "bridge": {"inbox":"<секретное имя ntfy‑топика>"},
 "updated_at": "ISO"
}
```
Загрузка: сначала `raw.githubusercontent.com/.../data/site.json` (свежее), фолбэк — локальная копия; повтор каждые 60 с при видимой вкладке; после применения — событие `site:data`, на которое подписаны менеджеры/FAQ/чат. Режим `maintenance` показывает заглушку.

## 8. Онлайн‑чат (chat.html + js/chat-app.js + css/chat.css)
- Отдельная страница; на десктопе окно 720px по центру, на мобиле full‑screen (`100dvh`, safe‑area, подстройка под клавиатуру через `visualViewport`).
- Шапка: назад, аватар/имя менеджера (после «joined»), статус (онлайн / друкує… / діалог завершено), кнопка **«Закрити чат»**, меню ⋮ (Telegram, сменить имя, завершить диалог, очистить историю).
- Лента: разделители дней, группировка, галочки ✓/✓✓, «не надіслано · повторити», системные плашки «Менеджер X приєднався» / «Діалог завершено», индикатор печати, кнопка «вниз» со счётчиком.
- Быстрые кнопки (Забронювати / Ціна / Посилка / Трансфер), поле имени, textarea с автовысотой, Enter — отправить (на десктопе).
- **Файлы**: скрепка, drag‑and‑drop, paste; до 5 за раз; изображения сжимаются в JPEG ≤1600px (лимит ntfy — 2 МБ/файл); прогресс загрузки; превью/лайтбокс; документы карточкой. Полученные фото кешируются миниатюрой в localStorage (вложения ntfy живут 3 ч).
- Транспорт: исходящие — `POST https://ntfy.sh/<INBOX>` (JSON) или `PUT` с файлом + заголовок `Message` (base64 JSON‑метаданные); входящие — `EventSource https://ntfy.sh/<INBOX>-r-<sid>/sse?since=<lastId>`. `sid` — случайный 16‑hex id посетителя в localStorage.
- События протокола: от сайта `chat`, `chat_typing`, `chat_open`, `chat_name`, `chat_end`, `lead`; от бота `{text,by}`, `{typing}`, `{seen}`, `{joined:name}`, `{ended}`, вложение.
- Оффлайн‑баннер, автоповтор при `online`, web‑notifications, бейдж непрочитанных на главной (через `storage`‑событие и SSE).

## 9. Telegram‑бот (bot/bot.py)
- Python 3.12, только стандартная библиотека, long‑polling `getUpdates`. Реагирует только на `ADMIN_ID` (владелец) и добавленных им админов; остальных игнорирует.
- Хранение: правит `data/site.json` и `bot/state.json` через GitHub Contents API (commit от бота); Pages передеплоивает сайт → изменения видны через 1–3 мин.
- Главное меню (inline‑кнопки): 📥 Заявки · 💬 Чати · 🛣 Маршрути (цены, старая цена, бейдж, скрыть, массово ±%) · ⭐ Відгуки · ❓ FAQ · 🏠 Головна (заголовок, подзаголовок, преимущества) · 👤 Менеджери (добавить/имя/посада/телефон/Telegram/WhatsApp/порядок/удалить; внутри — «Загальні контакти») · 📢 Оголошення · 🟢/🔴 Техроботи · 👥 Адміни · 📊 Журнал · 🌐 Сайт · /backup.
- Ввод значений — через «pending»‑диалог (бот просит текст, кнопка «Скасувати»).
- **Заявки**: приходят как карточка с полями + ссылки WhatsApp/Telegram по номеру + кнопки «▶️ Почати діалог» и «✅ Опрацьовано».
- **Чат — режим диалога**: «Почати діалог» → клиент видит «менеджер приєднався»; далее всё, что админ пишет боту (текст, фото, документ, видео, голос), уходит клиенту; сообщения клиента приходят обычным текстом, файлы — как фото/документ; статус «печатает». «⏹ Завершити діалог» / `/end` → клиенту «Діалог завершено». Свайп‑ответ на сообщение клиента тоже включает диалог. Заготовки быстрых ответов (CANNED).
- Слушатель ntfy: отдельный поток читает `https://ntfy.sh/<INBOX>/json?since=<id>` и диспатчит события; `since` сохраняется, чтобы не терять сообщения при перезапуске.
- Жизненный цикл: `MAX_RUNTIME=19200` с (5 ч 20 мин) → выход → шаг «Restart myself» запускает workflow заново; cron каждые 30 мин — сторож; concurrency‑guard не даёт двум копиям работать одновременно.
- Секреты в GitHub: `BOT_TOKEN`, `ADMIN_ID`, `GH_PAT` (contents:write).

## 10. Деплой и эксплуатация
- Любой push в `main` → Pages‑деплой (~2 мин, live через 3–4 мин). Кэш‑бастинг: `site.json` грузится с `?v=<время/15с>`.
- Правило: перед push всегда `git pull --rebase` (бот коммитит state.json).
- Проверки перед релизом: Playwright‑скриншоты 1440/1024/390, отсутствие JS‑ошибок, прогон всех форм (7 лидов), меню, календарь.
- Лимиты ntfy free: ~250 сообщений/час с IP, 2 МБ на файл, 20 МБ вложений, хранение файлов 3 ч, сообщений 12 ч.

## 11. Как повторить с нуля (порядок)
1. Создать репозиторий на GitHub, включить Pages (Deploy from branch `main` или Actions).
2. Сверстать `index.html` с разделами из п.5, подключить шрифт, `light-v6.css`, скрипты из п.3.
3. Создать `data/site.json` по схеме п.7 и `site-data.js`, который применяет его к DOM.
4. Реализовать формы (п.6) и мост `site-bridge.js` → ntfy‑топик со случайным секретным именем.
5. Сделать `chat.html` + `chat-app.js` (п.8).
6. Написать бота (п.9): BotFather → токен; узнать свой Telegram id; секреты в репозиторий; `bot.yml` с самоперезапуском.
7. Привязать домен: `CNAME` в репо, A‑записи и `www` CNAME у регистратора, дождаться сертификата, включить Enforce HTTPS.

## Адаптивность (css/responsive.css)
- Сайт не имеет min-width (убран `.app{min-width:350px}`), html/body `overflow-x: clip`; контейнер `min(1340px, 100% - 40px)`; на ≥1700px — 1400px.
- Заголовки — fluid `clamp()`; hero всегда вертикальный стек; 600–1099px — карточки маршрутов и преимущества в 2 колонки; ≤359px — компактные отступы.
- Инпуты на мобильных ≥16px (нет автозума iOS).

## Чат (chat.html) — мессенджер-стиль
- Пузыри с «хвостиками», время и галочки внутри пузыря, группировка подряд идущих сообщений, точечный фон, липкие даты.
- Клавиатура: `html,body{position:fixed}` + высота приложения из `visualViewport` (`--vvh/--vvt`), класс `.is-kb` скрывает подсказки; поле ввода всегда прижато к клавиатуре.
